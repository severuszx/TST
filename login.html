一、我们如何收集和使用个人信息

我们收集您的个人信息主要是为了向您提供更优质、更稳定的服务体验。我们仅会出于本政策所述的目的收集和使用您的个人信息。

1.1 您主动提供的信息
当您使用本服务器官网的以下功能时，您可能会主动向我们提供以下信息：
（1）官网账户注册与登录：当您注册或登录官网账户时，我们会收集您的邮箱地址、验证码及您设置的密码（密码仅以加密哈希形式存储），用于账户身份验证和安全登录。
（2）游戏账号绑定：当您在官网绑定游戏账号时，我们会收集您的游戏 UID，用于关联您的游戏数据。该数据仅用于在您登录后向您本人提供个人数据查询服务，不会在官网公开展示。
（3）反馈中心提交：当您通过官网反馈中心提交问题或建议时，我们会收集您填写的游戏 ID、反馈类型、发生时间、联系方式、问题描述及您主动上传的截图。其中"联系方式"为选填项。
（4）商城兑换与赞助：当您使用官网商城的积分兑换功能时，我们会记录您的兑换记录；当您进行赞助时，我们会记录您的赞助金额及您选择是否公开鸣谢的意愿。
（5）抽奖活动：当您参与官网抽奖活动时，我们会记录您的抽奖结果及参与时间。

1.2 我们自动收集的信息
当您访问本服务器官网时，我们可能会自动收集以下技术信息：
（1）设备信息：官网部分页面（如"我的"页面）会在您的浏览器中本地检测并显示 CPU 核心数、GPU 信息、内存大小、网络类型、屏幕分辨率等信息，此类信息不会上传至服务器。但当您参与官网抽奖活动时，为防范刷奖行为，我们会收集并上传设备指纹信息至服务器端，用于防刷验证。
（2）IP 地址：当您访问本服务器官网、提交反馈、参与抽奖时，我们会主动收集您的 IP 地址，并将 IP 地址与访问日期一同记录至服务器端数据库，用于防刷验证、异常访问检测及安全审计。
（3）日志信息：访问时间、访问页面、操作记录等，用于服务维护与安全审计。
（4）Java 服在线状态：官网首页展示 Java 版服务器「the slow tide」的在线人数、在线玩家昵称与头像。该数据由服务器插件定时上报，仅包含游戏昵称、游戏内标识与皮肤地址，不含现实身份信息；玩家下线后即从展示列表移除。

· 验证您的身份，保障账户安全；
· 处理您的反馈、建议与申诉；

十、附录：相关定义

个人信息：指以电子或者其他方式记录的能够单独或者与其他信息结合识别特定自然人身份或者反映特定自然人活动情况的各种信息。
个人敏感信息：指一旦泄露、非法提供或滥用可能危害人身和财产安全，极易导致个人名誉、身心健康受到损害或歧视性待遇的个人信息。
匿名化：指通过对个人信息的技术处理，使得个人信息主体无法被识别，且处理后的信息不能被复原的过程。
去标识化：指通过对个人信息的技术处理，使其在不借助额外信息的情况下无法识别个人信息主体的过程。
